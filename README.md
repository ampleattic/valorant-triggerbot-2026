## FAQ

**How do I reduce obvious triggering?**  
Set pre-fire delay to 30–80ms and enable reaction randomisation. This mimics human response times.

**Does it work with all gun types?**  
Yes — rifles, pistols, snipers. Set a longer post-fire delay for snipers to avoid accidental double-fire.
